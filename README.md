# Java Calculator Project

자바 기반의 콘솔 계산기 프로그램입니다.

## Features
- 사칙연산 지원 (+, -, *, /)
- Enum 기반 연산자 관리
- 연산 로직 분리
- 잘못된 입력 예외 처리

## Exception Handling
- 0으로 나누는 경우 예외 발생
- 지원하지 않는 연산자 입력 시 오류 메시지 출력
- 양의 정수를 제외한 입력 시 오류 메시지 출력
- 비교값 숫자를 제외한 입력 시 오류 메시지 출력

## Future Improvements
- ArithmeticCalculator 제네릭과 Enum 타입 구현 개선 필요
